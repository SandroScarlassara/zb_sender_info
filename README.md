# Projeto para exportação de contadores do SQL para o Zabbix atravës do Zabbix Sender.

### IMPORTANTE: Precisa ter o Microsoft .Net Runtime 10 instalado


**Passos para Instalação**.

1. Copiar os arquivos para o diretório C:\Program Files\Zabbix Agent\conf
    - database_counter.json
    - instance_counter.json
    - instance.json
2. Editar o aquivo instance.json
    - Modificar as váriaveis da instância conforme necessidade.
